# 👗 像素衣橱

给 `{{user}}` 换装的酒馆助手脚本。右下角一个小人悬浮球 —— 球上就是你现在这身打扮。
点开是衣橱：左边纸娃娃，右边挑衣服挑颜色。挑完按「穿好了」，这套穿搭就进每次生成，
AI 写到你的时候按这身写。

任何卡都能用，装一次就行。

---

## 装法

酒馆助手 → 脚本库 → 导入 → 选 `pixel_wardrobe_online.json`（在线版，本体和素材都从云端拉，
作者更新你不用重导）→ 装到**全局**。

装好以后：

- QR 栏多一个「👗 衣橱」按钮
- 右下角出现悬浮球，球上画着你现在的样子

悬浮球拖丢了、被别的脚本清掉了、或者干脆不见了 —— 按 QR 栏那个「👗 衣橱」，它会自己回来。

---

## 怎么玩

1. **选素材包**：右上角「女生 / 男生 / 恩希」。选了会记住，跟着你走，不跟着卡。
   前两个是 LPC 那副身体，第三个是画师 **恩希** 从零画的一副萌版身体（见下面「画师专区」）。
   每个包各记各的穿搭和长相，换来换去不会串。
2. **挑衣服**：下面七页 —— 肤色·脸 / 发型 / 头饰配饰 / 上装 / 下装 / 鞋 / 手持。
   「手持」是右手拿的东西：咖啡杯、书、手机、雨伞、花束、酒杯、玫瑰、蜡烛、羽毛……
   （男生版暂时还没有这一页。）
   默认只显示「精选」（每页十几到几十件，一屏翻得完）；想看全部就点「全部」，
   兽首、翅膀、尾巴这类收在最底下的「奇幻」里，点开才出来。
   女生版里还有一组**主题装**（情趣内衣、猫女、女仆、兔女郎、水手服、旗袍、
   婚纱、睡裙、比基尼……），是专门给这个衣橱画的，别处没有。
3. **挑颜色**：点一件衣服，上面出现色块条。默认给 12 个好搭的颜色
   （莫兰迪、婚礼两套自配色 + 黑白藏青）；点「更多颜色」能看到全部，
   按配色板分好了组。
4. **穿好了**：按底下那个粉色的按钮，这套穿搭就以一句话进对话。
   换了衣服记得再按一次。不想让 AI 再看到就按「脱下」。
5. **改词**：不满意自动写的那句？按「✎ 改词」，textarea 里随便改，改完再按「穿好了」。

### ⚙ 设置

面板顶栏那个 ⚙ 点开：

- **显示悬浮球**（默认开）—— 不想要球就关掉，只从 QR 栏的「👗 衣橱」进衣橱。
  想要回来在这儿再点开。
- **球贴边半藏（手机）**（默认开）—— 球靠着屏幕边几秒没人碰就滑进边里一半、变淡，
  不挡正文；碰它或者开衣橱就出来。电脑上不藏。

### 🔞 NSFW 是第三个视图，不是开关

筛选条上三颗药丸是**三选一**：

| | 看到什么 |
|---|---|
| **精选** | 挑过的日常款，不含成人向单品 |
| **全部** | 这一页全部，成人向的也在里面 |
| **NSFW**（虚线那颗） | **只**看这一页的成人向单品 —— 想找不用翻，一屏都在那儿 |

「🎲 随机一套」跟着当前视图摇：在精选摇不到成人向的，在 NSFW 视图只摇成人向的。
某一页要是一件都没有，点 NSFW 会写「这一栏没有 NSFW 单品」。

（成人向的那些是：几件情趣内衣、吊带袜和吊袜带、口球、项圈牵绳、绳缚、手铐，
以及皮鞭马鞭皮拍。套装里的「情趣内衣」和别的套装一样排在那条上。）

### 🎨 娃娃底色

娃娃下面那排小圆点：**透明格子 / 深灰 / 浅灰 / 米白 / 雾霾蓝 / 淡粉 / 墨绿**。
白衣服在浅底上、黑衣服在深底上都会糊得看不清，挑一个能看清的底就行。
选了以后**娃娃和右边格子里的小图一起换**（小图看不清等于没挑）。记在全局，跟着你走。

### 🎨 画师专区：「恩希专区」（v0.4 新）

顶栏第三颗药丸。这是**第一个画师投稿包** —— 一副完全不一样的萌版身体（大头、手臂张开），
和它自己的 22 件东西，全部由画师 **恩希** 原创：

| | |
|---|---|
| 脸 | 身体（8 档肤色）· 两种眼睛（黑色眼睛 / 眯眯眼，8 个眼色）· 腮红 · 口罩 · 半框眼镜 |
| 发型 | 短发 · 长直发 · 双马尾（各 26 个发色） |
| 头饰 | 蝴蝶结 · 恶魔角 · 猫耳朵 |
| 上装 / 下装 / 鞋 | 短袖 T 恤 · 短袖衬衫 · 无袖连衣裙 / 长裤 · 短裙 / 长靴 · 高帮运动鞋 |
| 尾巴 | 猫尾巴 · 狐狸尾巴 · 恶魔尾巴 |

衣服、头饰、尾巴照旧 48 色，发型 26 色。这一包和 LPC 那两个包是**两副不同比例的身体**，
所以衣服不通用 —— 换包的时候各穿各的，你在这边打扮的样子会单独记着。

（署名：恩希，CC-BY-SA 3.0，见 `assets/nini/CREDITS.txt`。想投稿的看下面「会画像素的话」。）

### 单件小物

尾巴（狐 / 狼 / 猫 / 兔 / 龙 / 恶魔）、兽耳、天使光环、眼罩、面具、项圈 —— 都是**单件**，
各占各的一格，和别的衣服随便搭。兔耳占的是耳朵那格不是帽子那格，所以兔耳配女仆帽也行。

### 长相和衣服是两回事

脸和身材捏好了通常就不会再动，所以这两样分开管：

- **🧺 全脱只脱衣服** —— 肤色、脸、头发都还在，不会剩一张飘着的脸。
- **身体和脸永远不会空**：真空了会自动补回默认那张，想换直接点另一张就行。
- **🎲 随机一套** 只摇衣服；想换张脸按旁边的 **🙂 随机长相**。
- **存为一套 / 我的穿搭 / 套装 只管衣服** —— 换穿搭永远不会顺手把你的脸换掉。

（从 v0.1 升上来的老存档会自动分好，你什么都不用做。）

### 还有这些

- **👗 套装** —— 面板上面那一条是十套现成搭配（女仆、猫女、兔女郎、婚纱……），
  点一下整套换上。里头带的猫耳这种只换那一格，脸和发型不动。
- **🎲 随机一套** —— 手气不好就再摇一次。
- **💾 存为一套** —— 给现在这身起个名字（约会装、睡衣、上班……），
  存好以后出现在「套装」下面那一排，点一下就换上，点 × 删掉。
- **❤️ 收藏** —— 每件衣服右上角那个心，收的是「这件 + 这个颜色」。
  收了至少一件，最左边就多出一页「收藏」。
- **穿搭跟着聊天走** —— 每个聊天各存各的一套，换卡不会串。
  开新聊天时默认接着你上次那身穿。
- **收藏和「我的穿搭」跟着你走** —— 存在全局，换卡换聊天都在。

## 常见问题

**AI 不理我的穿搭？**
先确认底下那行写的是「✔ 这身正在进对话」。如果写的是「还没进对话」，按一下「穿好了」。
另外，穿搭是以一句系统提示插在对话里的，预设如果把系统提示都压掉了，效果会打折。

**它会不会每轮都复述我穿了什么？**
插进去的那句话末尾专门写了「不必每轮复述」。真遇到复述狂魔，去「✎ 改词」里
把要求写得更硬一点。

**娃娃缺一层 / 有的东西画不出来？**
素材是按分类分批下载的，网络慢的时候会一层层补上来。要是一直缺，
看看是不是 jsDelivr 被挡了 —— 面板会弹提示告诉你哪张图集没下来。

**手机上悬浮球乱跑 / 面板飘出屏幕？**
拖一下球，位置会记住（手机和电脑分开记）。实在找不着就按 QR 栏的「👗 衣橱」。

**衣服太多翻不动？**
那就别点「全部」，精选那一屏是专门挑出来的日常款。

## 会画像素的话

**「恩希专区」是第一个，位置还有。** 画一件就能上；画一副身体，整个专区挂你的名字。

我们在招画师，尤其想要一副**更可爱的身体**（动森那种圆滚滚的比例）。
发布包里有 `投稿模板/` 文件夹：身体模板（原始大小 + 8 倍带格）、色阶表、一件范例。
`preview.html` 里可以把你画的 PNG 直接拖进去穿在娃娃身上看效果，不用装任何东西。
细节看 `投稿模板/README.md`。
