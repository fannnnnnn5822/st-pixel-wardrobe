# 像素衣橱 · 画师投稿指南

像素衣橱是一个酒馆助手（Tavern Helper）全局脚本：玩家打开一个衣橱，给 {{user}} 点点点换装，穿好后一键变成穿搭描述进对话。所有衣服都是分层的小像素图，叠在同一副身体上。

现在的身体来自开源素材库 LPC（90 年代 RPG 画风，手肘内收，我们叫它猩猩胳膊）。我们想要一副**更可爱的身体**，动物森友会那种圆滚滚的比例。这需要真正会画像素的人。

投稿有两条路，任选：

- **A. 给现有身体画单件**：门槛低，画一件就能上。
- **B. 画一副新的可爱身体（萌版包）**：门槛高，但整个包会以你的名字命名。

---

## 通用规则（两条路都适用）

| 项目 | 要求 |
|---|---|
| 文件格式 | PNG，透明背景（带 alpha 通道） |
| 画布 | 固定 **64 × 64** 像素，一件一个文件 |
| 视角 | **正面站立，一帧**，不用动画 |
| 像素 | 1:1 原始像素，**不要**放大后再缩小，**不要**抗锯齿、模糊、渐变 |
| 位置 | 直接画在我们提供的身体模板上，导出时**只留你画的那一层**，身体不要一起导出 |
| 前后层 | 有身后部分的（尾巴、长发后半、披风背面）分成两个文件：`名字_front.png` 和 `名字_back.png` |
| 配色 | 主材质最多 **6 个色阶**（高光到阴影）。用一种"标准色"画就行，比如白色或中灰，衣橱会自动染成 48 种颜色。金属、宝石这类不想被染色的部分单独说明 |
| 描边 | 深色描边，光源左上（和现有衣服一致） |
| 命名 | 小写英文加下划线，如 `top_sailor_blouse.png`、`hand_feather.png` |

每件附一行信息（写在一个 txt 里就行）：

```
文件名 | 中文名 | 槽位 | 是否 NSFW | 署名 | 备注
top_sailor_blouse.png | 水手服上衣 | 上装 | 否 | 阿花 | 领子是白的不染色
```

槽位可选：`肤色/脸`、`发型`、`头饰配饰`、`脸饰`、`上装`、`下装`、`鞋`、`手持`、`尾巴`。

**中文名就是提示词**。玩家穿上后，AI 看到的是"水手服上衣"这四个字，所以名字要具体，不要写"衣服 1"。

## 路线 A：给现有身体画单件

1. 从仓库下载 `投稿模板/` 文件夹，里面有：
   - `body_female_1x.png` / `body_male_1x.png`：身体模板，原始大小
   - `body_female_8x_grid.png`：放大 8 倍带格子的版本，方便对位（**只用来看，不要在上面画**）
   - `palette.png`：现有衣服用的色阶，取色用
   - `example_top.png` + `example_top.txt`：一件范例和它的信息行
2. 在 Aseprite / Piskel / Photoshop 里打开 1x 模板，新建一层画衣服。
3. 隐藏身体层，导出 64×64 PNG。
4. 用 `preview.html` 本地打开看效果（拖你的 PNG 进去就能穿在娃娃身上）。

## 路线 B：画一副萌版身体

这是我们最想要的。要求比路线 A 多一些，因为整个包的衣服以后都要画在这副身体上。

**身体设计**

- 画布还是 64×64，角色高度 40 到 52 像素之间，头大身小（2.5 到 3 头身），手臂自然下垂或微微张开。
- 身体和头画在**一张**图上（不像 LPC 那样分开）。
- **眼睛单独一张**，这样玩家能换眼色。
- 肤色用一条 4 阶色阶画，我们负责染出其他肤色。
- 请给一张"没穿衣服的底"（内衣级别即可），衣服都叠在它上面。

**启动包最少要有**

| 类别 | 数量 |
|---|---|
| 身体（含头） | 1 |
| 眼睛 | 1 |
| 发型（前 + 后各一张） | 3 |
| 上装 | 3 |
| 下装 | 2 |
| 鞋 | 2 |

有这些我们就能把包上线，之后再慢慢加。男生版可以之后再画，不强求。

**提交前自检**

- 每件衣服叠在身体上，边缘不露肉、不穿模。
- 发型前后两层叠好后，和头的轮廓吻合。
- 缩到 1 倍大小仍然认得出是什么。

## 署名与许可

- 投稿即同意以 **CC-BY-SA 3.0** 发布（和 LPC 素材一致），这意味着别人可以在署名的前提下使用和改画。
- 你的名字会出现在衣橱的 CREDITS 文件里，套装或整个包可以用你的名字命名。
- 不接受从游戏、其他画师作品里扒下来的图。
