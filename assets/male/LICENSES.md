# 许可证 / Licenses

`atlas_*.png` 里的像素素材全部来自 **Universal LPC Spritesheet Character
Generator**（LPC，Liberated Pixel Cup）。我们只做了两件事：从每张原始
spritesheet 里裁出一帧正面站姿，以及用该仓库自带的调色板定义做换色。
这属于**衍生作品**，因此原始许可证继续生效。

源仓库： <https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator>

## 实际义务（最严格的那条说了算）

本次构建里同时存在 CC-BY-SA 3.0、OGA-BY 3.0 与 GPL 3.0 的素材，绝大多数文件
是三者并列授权（可任选其一遵守）。若按 **CC-BY-SA 3.0** 使用，需要：

1. **署名**：在作品里可被用户发现的位置（例如「关于/致谢」页）列出全部作者，
   或直接附上 `CREDITS.txt`。
2. **相同方式共享**：对这些像素素材本身的任何修改（含我们做的裁帧与换色）需
   以 CC-BY-SA 3.0 或更新版本发布。**这只约束美术素材本身，不约束调用它的
   代码或角色卡文本。**
3. **不得加 DRM**（不得用技术手段限制他人获取素材）。

若不想受 ShareAlike 约束，可改按 **OGA-BY 3.0** 使用：只需署名，且允许 DRM。
GPL 3.0 一路只在需要与 GPL 项目合并时才有意义。CC0 素材无需署名。
